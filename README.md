# Burios.cz - QPX Archer 
Projekt webové aplikace pro zpracování stránek archívů Matrik na data k použití uložení do databáze.
Ukládání souborů do vlastního uložiště (FileStore) na serveru, organizovaného pomocí webového rozhraní.

Postavený na:
- Java 17+
- Tomcat 11+.
- Spring 6+ MVC
- JSP
- JDBC

Jako front-end je použitý oQPX, vlastní javasript (jQuery) OOP UI kniovna.
